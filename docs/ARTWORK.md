# Original artwork

Design: midnight navy tile, mint/cyan shield and a bold check. The tray variant removes the tile and fine detail for legibility at small sizes. These are original geometric assets, not the Google Chrome logo.

- `assets/app.ico`: 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px.
- `assets/tray.ico`: 16, 20, 24, 32, 40, 48 and 64 px, transparent background.
- `assets/app.svg`, `assets/tray.svg`: editable vector variants.
- High-resolution PNG variants and the light/dark preview board are also included.
- `tools/IconArtwork.cs` and `scripts/build-icons.ps1`: deterministic Windows GDI+ generator.

Icon artwork is distributed under the repository's MIT license. No external icon font or third-party image is embedded. The icon is not a reliable indicator of authorization state; consult the tray menu and result text.
