# ChromeDevToolsAutoAllow v1.0.0

首次独立项目发布，基于 ChromeConsentGuard v1.2.1。

## 主要内容

- Chrome 原生远程调试弹窗的事件驱动识别与托盘状态。
- 默认仅检测，保留用户确认后的临时 / 永久模式及持久化设置。
- 严格匹配、网页排除、单按钮去重、未知结果停用。
- 原创多尺寸 EXE 图标和透明托盘图标。
- 标准解决方案、独立测试工程、构建与打包脚本、CI 和标签发布流程。

## 环境与升级

Windows x64 / .NET Framework 4.8。先退出旧版再运行新程序；不要把个人已启用的设置直接放入分享包。干净发布包默认只检测。

## 验证

重命名和工程拆分后，本机 72 项单元检查、128 项完整模拟检查通过（完整检查包含单元检查）。生产 EXE 不包含测试窗体入口。

已有一次前身版本的真实联调完成 MCP 连接，但不代表长期稳定性或跨版本保证；本次打包未重新操作真实安全授权。结果不明时需要人工处理，不会重复点击或追加输入。
