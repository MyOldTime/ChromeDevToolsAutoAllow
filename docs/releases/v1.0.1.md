# ChromeDevToolsAutoAllow v1.0.1

2026-11-05 修订后重新发布。托盘“状态”窗口的标题、启动提示和重复启动提示统一从应用程序集读取版本，显示为 `ChromeDevToolsAutoAllow 1.0.1`。

修复 Windows 上偶发的“识别到 Chrome 远程调试弹窗，但没有点下允许”。旧版可能在按钮刚出现时就调用它，Chrome 的防误触保护会忽略这次输入，导致弹窗停留、自动模式暂停。

自动模式现在会等待系统双击间隔加 250 毫秒，重新核对同一进程、弹窗和按钮，并确认自动模式仍然有效，然后调用一次。日志中的 `WAIT_BEFORE_INVOKE` 会记录实际采用的等待时长。

## 验证

- Windows x64 上的 138 项检查通过，其中包含 72 项单元检查。新增回归用例覆盖按钮已启用但仍处于输入保护期的情况。
- 在 Chrome 156.0.8078.80 的独立测试配置中，连续 3 次调试连接均成功。Chrome DevTools MCP 1.12.0 使用 `--autoConnect` 成功执行 `list_pages` 并读到了测试页。

## 下载与升级

Windows x64 用户请下载 `ChromeDevToolsAutoAllow-v1.0.1-windows-x64.zip`。从托盘退出旧版后即可替换原目录中的 EXE。沿用原目录时会恢复已保存的模式，新目录首次启动时只检测弹窗。

Release 另附源码 ZIP 和 SHA-256 校验清单。
